**Verdict:** the gate itself is well-built — honest disclosure, hashed secret answers, jurisdiction-aware consent, a genuinely current no-account registry route beside it. But the door that leads to it still undersells its price, its one recovery path dead-ends silently, and its own stated reason for existing isn't backed by anything in the codebase. None of F1–F29 covers any of the three.

**1. [instrumented] README's own door undersells the gate it points at.** `grep -n "one email" README.md`: line 4 — "the website download asks for a free account (one email)." The actual form (`components/download-account-form.tsx`) requires email, first name, password + confirm, a secret question **and** answer, plus a consent checkbox — six fields, one of them a password. `git show 8fa0a0d -- README.md` shows wave 2 grew the line directly above this one (the tagline) and left it untouched — the door I signed off on in R5 for the registry-name fix, re-walked now for a different reason. `/downloads` itself is accurate ("email, first name, a password and a security question, no card") — so the honesty fix from wave 1 exists one page later than the first place a stranger reads the cost. This is the smallest possible bait-and-switch: a reader decides at README to trade one email, then meets a password and a secret question at the door.

**2. [instrumented] The one recovery path swallows its own lockout.** `grep -n "too_many_attempts" app/api/account/reset-complete/route.ts app/account/reset/page.tsx`: the API returns a distinct `too_many_attempts` code (route.ts:76), but the client (`reset/page.tsx:82-87`) only branches on `wrong_answer` and `password_too_short` — anything else, including the lockout, falls into `"Something went wrong. Try again in a moment."` Orbit has no transactional-email system (stated explicitly at `app/api/email-reset/route.ts:28` and `app/account/email/page.tsx:227`), so the secret question is the *only* recovery mechanism this account has. A stranger who trips the rate limit is told to retry shortly, not that they're locked, and is never pointed at `/contact` or the ungated GitHub/registry fallback at the exact moment they need one. F1–F29 has nothing on this path; iteration 1 never opened `reset/page.tsx`.

**3. [instrumented] The gate's stated reason has no engine behind it.** `/downloads` justifies the account as "so I can reach you about the build you're on." `grep -rn "no transactional" app/`: two files say outright Orbit "has no transactional-email system" (`app/api/email-reset/route.ts:28`, `app/account/email/page.tsx:227`), and nothing in `lib/` or `app/api/` sends outbound mail — no Resend, Postmark, SendGrid, SMTP client, nothing beyond content pages that mention those terms as course material. The consent checkbox governs an opt-in *marketing* list, which an EU/UK/AU visitor can leave unticked — for that visitor, and arguably for everyone until an external send pipeline exists, the reason given for the friction is aspirational, not a live capability, and nothing on the page flags it as such.
